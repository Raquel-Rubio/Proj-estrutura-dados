# **READ ME**

Projeto 1 da matéria Estrutura de Dados

Sistema de registro de reparos de equipamentos, programado em C.
O sistema inclui a capacidade de incluir pedido, excluir pedido, verificar informações sobre um pedido, modificar prioridade e/ou periodo, imprimir os pedidos por ordem de prioridade e imprimir todos os pedidos ordenados pelo código de solicitação.

Todos os pedidos devem conter as seguintes informações, informadas pelo usuário:
 - Código de Solicitação
 - Código do Equipamento
 - Nome do Equipamento
 - Prioridade do Pedido (de 1 a 3)
 - Período do Reparo
    - Para Prioridade 1: de 1 a 7 dias
    - Para Prioridade 2: de 1 a 15 dias
    - Para Prioridade 3: de 1 a 20 dias

>[!NOTE]
>Esse projeto tem objetivos puramente educacionais

Os únicos arquivos que estão funcionais no projeto final são: Main.c e Lista.h, todos os outros foram criados com o intuito de testar o código.
