# **READ ME**

Projeto 1 da matéria Estrutura de Dados

Sistema de registro de reparos de equipamentos, programado em C.
O sistema inclui a capacidade de incluir pedido, excluir pedido, verificar informações sobre um pedido, modificar prioridade e/ou periodo, imprimir os pedidos por ordem de prioridade e imprimir todos os pedidos ordenados pelo códifgo de solicitação.
Todos os pedidos devem conter as seguintes informações, informadas pelo usuário:
Código de Solicitação
Código do Equipamento
Nome do Equipamento
Prioridade do Pedido (de 1 a 3)
Periodo do Reparo (varia para cada nível de prioridade)

>[!NOTE]
>Esse projeto tem objetivos puramente educacionais
